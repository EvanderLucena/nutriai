**Backend: WhatsAppIntelligenceController** — REST controller per D-23:

```java
@RestController
@RequestMapping("/api/v1")
@PreAuthorize("hasRole('NUTRITIONIST')")
public class WhatsAppIntelligenceController {

    // 1. GET /api/v1/patients/{id}/extractions — list today's extractions (D-23)
    //    - Extract nutritionistId from JWT
    //    - Call WhatsAppIntelligenceService.getExtractionsToday(patientId, nutritionistId)
    //    - Return ApiResponse.ok(List<ExtractionDTO>)
    //    - 404 if patient not found or not owned by this nutritionist

    // 2. PATCH /api/v1/patients/{id}/extractions/{extractionId} — correct extraction (D-12, D-21, D-23)
    //    - Accepts PatchExtractionRequest body with items[]
    //    - Call WhatsAppIntelligenceService.correctExtraction(patientId, nutritionistId, extractionId, request)
    //    - Return ApiResponse.ok(ExtractionDTO) with updated data
    //    - 404 if extraction not found or not owned
    //    - Updates MealExtraction totals when items change (recalculate from items)

    // 3. GET /api/v1/patients/{id}/activation-link — generate WhatsApp link (D-15, D-23)
    //    - Extract nutritionistId from JWT
    //    - Load patient, check Patient.whatsapp is not null
    //    - If null: return ApiResponse.error("WhatsApp não cadastrado") with 400
    //    - If not null: generate link format "wa.me/55{DDD+number}?text=Oi"
    //    - Return ApiResponse.ok(ActivationLinkDTO)

    // 4. GET /api/v1/whatsapp/status — WhatsApp instance health (D-23)
    //    - Call WhatsAppIntelligenceService.getWhatsAppStatus()
    //    - Return ApiResponse.ok(WhatsAppStatusDTO)
    //    - Checks Evolution API connectivity + count of patients with ≥1 message
    //    - This does NOT call Evolution API health endpoint directly
    //    - Instead, checks last webhook received timestamp + counts from DB
}
```

**WhatsAppIntelligenceService** — Business logic:

For `getExtractionsToday`:
- Query MealExtraction by patientId + nutritionistId + extractedAt between startOfDay and endOfDay
- Map to ExtractionDTO (includes nested ExtractionItemDTO list)
- Sort by extractedAt DESC

For `correctExtraction` per D-12:
- Load MealExtraction by id + patientId + nutritionistId (tenant check)
- Delete existing ExtractionItems and replace with new ones from request
- Recalculate totals (sum of item macros)
- Update MealExtraction totals in the database
- Update the related EpisodeHistoryEvent metadataJson with the corrected items
- Return updated ExtractionDTO

For `getActivationLink` per D-15:
- Load Patient by id + nutritionistId
- If Patient.whatsapp is null → return error
- Normalize phone number (already normalized in DB, but strip any remaining non-digits)
- Format: `https://wa.me/55{phone}?text=Oi` (D-15: "Oi" is the default message, convenience link)
- Check if patient has sent at least 1 WhatsApp message (isActivated flag)
- Return ActivationLinkDTO with link, phone, and isActivated boolean

For `getWhatsAppStatus`:
- Count patients with ≥1 WhatsApp message for this nutritionist (isActivated)
- Count today's extractions for this nutritionist
- Get timestamp of most recent webhook message (any phone number, last 24h)
- Return WhatsAppStatusDTO with: connected (boolean based on recent webhook activity), extractionsToday, activePatientsCount, lastWebhookAt

```typescript
import { apiClient } from './client';
import type { Extraction, ActivationLink, WhatsAppStatus, PatchExtractionPayload } from '../types/whatsapp';

export const whatsappApi = {
  getExtractions: (patientId: string) =>
    apiClient.get<{ success: boolean; data: Extraction[] }>(`/patients/${patientId}/extractions`),

  patchExtraction: (patientId: string, extractionId: string, payload: PatchExtractionPayload) =>
    apiClient.patch<{ success: boolean; data: Extraction }>(`/patients/${patientId}/extractions/${extractionId}`, payload),

  getActivationLink: (patientId: string) =>
    apiClient.get<{ success: boolean; data: ActivationLink }>(`/patients/${patientId}/activation-link`),

  getStatus: () =>
    apiClient.get<{ success: boolean; data: WhatsAppStatus }>('/whatsapp/status'),
};
```
